STEP 2: Add the hotkey handler in KeyboardHookFunction
================================================================================

Find the section with hotkey handlers (around line 250-330). Add this case:

        $5D : begin     // MENU KEY (line ~251)
                InterpretCommand('showranges', 1);
              end;

ADD THIS NEW CASE after any existing hotkey (e.g., after $5D):

        $DD : begin     // Alt + Shift + ]  →  Open COB Console
                if ( ((GetAsyncKeyState(VK_MENU) and $8000) > 0) and
                     ((GetAsyncKeyState(VK_SHIFT) and $8000) > 0) ) then
                begin
                  HandleConsoleHotkey;
                  Result := 1;
                  Exit;
                end;
              end;


STEP 3: Initialize the console on startup
================================================================================

In the implementation section where OnInstallKeyboardHook is called, add:

Procedure OnInstallKeyboardHook;
begin
  keyboardHookLevel := 2;
  lastShareEnergyVal := 0;
  hKeyboardHook:= SetWindowsHookEx(WH_KEYBOARD, @KeyboardHookFunction, 0, GetCurrentThreadId);
  Semaphore_IdleFactory := CreateSemaphore(nil, 1, 1, '');
  RegisterCOBConsole;  {<-- ADD THIS LINE}
end;


STEP 4: Cleanup on uninstall
================================================================================

In OnUninstallKeyboardHook, add:

Procedure OnUninstallKeyboardHook;
begin
  UnregisterCOBConsole;  {<-- ADD THIS LINE}
  CloseHandle(Semaphore_IdleFactory);
  if (hKeyboardHook <> 0) then
    UnhookWindowsHookEx(hKeyboardHook);
end;


HOTKEY REFERENCE:
================================================================================

Alt + Shift + ]  →  Toggle COB Console on/off

The console appears in an MS-DOS style interface with:
  - Unit Operations (health, kills, cloak, damage, team, allied status)
  - Movement & Position (coordinates, speed, angles, distance)
  - Search Units (near, yardmap, whole map, nearest)
  - Weapons & Combat (fire, reload, locked target, under attack)
  - Orders & Commands (move, orders, abort)
  - Map & Area (sea level, lava, metal, test positions)
  - Effects & Sound (3D sound, animations, effects, speech, features)
  - Game Info (map information)


NOTES:
================================================================================

1. The console integrates with COB_extensions.pas automatically
2. No database changes needed - just copy COB_Console.pas and modify KeyboardHook.pas
3. The hotkey follows your existing pattern (Alt+Shift+letter)
4. Console is non-blocking and can be toggled on/off at any time
5. All functions show which COB Extension they call internally
6. No removal needed - COB_Console is a NEW unit, not a replacement
